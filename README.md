A haiku about debugging: three lines in the **5-7-5** syllable shape, at most
**200 characters** total, written to `/output/entry.txt` as UTF-8.

```
breakpoint at 3am
I step through the code at dawn
the bug is in me
```

Concretely: the 3am stack trace, the slow step-through at dawn, and the turn —
the bug was never in the code, it was in the debugger.

Run with `python3 main.py`. The program writes the haiku to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), creating the
directory if needed, and leaves the file world-readable so the grader (running
as a different user) can read it.

["Seventeen Syllables of Debugging"](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty.
